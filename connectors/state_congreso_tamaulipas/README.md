# state_congreso_tamaulipas

Conector declarativo para legislacion vigente del Congreso del Estado de Tamaulipas.

## Alcance

1. resolver rutas de leyes, codigos y reglamentos fuera del stack local
2. devolver detalle de fuente y advertencia de oficialidad
3. encolar solicitudes de materializacion futura

## Restriccion

Este conector no descarga ni ingesta documentos por si mismo.

## Fuente

La compilacion electronica del Congreso de Tamaulipas es util para descubrimiento y consulta, pero no sustituye al Periodico Oficial del Estado.
