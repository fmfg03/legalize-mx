# Cross-Project Intelligence

Discover successful patterns across multiple projects and apply learned knowledge to improve development practices and architectural decisions.

## Commands

**`analyze`** - Analyze project for cross-project patterns
- Usage: `claude-intelligence analyze ~/project-path`
- Example: `claude-intelligence analyze ~/my-react-app`
- Discovers: Reusable patterns, architectural decisions, best practices

**`suggest`** - Get pattern suggestions for current project
- Usage: `claude-intelligence suggest .`
- Based on: Similar successful projects and proven patterns
- Provides: Actionable recommendations and implementation guidance

**`insights`** - View system-wide intelligence insights
- Usage: `claude-intelligence insights`
- Shows: Cross-project trends, success patterns, optimization opportunities
- Analytics: Pattern effectiveness across different project types

## Intelligence Features

- **Pattern Recognition** - Identifies successful architectural patterns
- **Knowledge Transfer** - Shares solutions between similar projects
- **Best Practice Discovery** - Learns from successful implementations
- **Project Similarity Analysis** - Finds projects with similar characteristics
- **Success Prediction** - Predicts likely success of proposed approaches

## Use Cases

- **New Project Setup** - Apply proven patterns from similar projects
- **Architecture Review** - Compare against successful similar projects  
- **Refactoring Decisions** - Use patterns from successful refactors
- **Technology Adoption** - Learn from successful technology migrations

## Execution

Leverage cross-project intelligence:

```bash
claude-intelligence {{args}}
```
